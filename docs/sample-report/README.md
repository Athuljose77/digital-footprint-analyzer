# Sample report

This folder contains a synthetic example of the report exported by the
desktop app:

- [sample-report.pdf](sample-report.pdf)
- [sample-report.json](sample-report.json)
- [sample-report.csv](sample-report.csv)

Every value is invented demo data. The report does not come from a real
device, account, browser profile, or file, and it must not be replaced with
output from a real scan.

Regenerate the files from the project root:

```bash
.venv/bin/python scripts/generate_sample_report.py
```

On Windows:

```bat
.venv\Scripts\python scripts\generate_sample_report.py
```
